# Original AI Almanac illustrations

These SVG drawings were created for AI Almanac. They do not reproduce a vendor
diagram or depict a specific commercial chip or network topology.

- `model-study.svg`: token vectors, a causal attention pattern, and a prediction.
  The values and bar lengths are illustrative. Hatching marks future positions.
- `silicon-study.svg`: compute tiles, memory banks, and connecting traces in a
  conceptual accelerator package. This is not a physical floorplan.
- `systems-study.svg`: eight compute nodes and illustrative communication paths.
  The drawing does not prescribe a particular fabric or collective algorithm.

Each has a 840 × 560 view box, an accessible title and description, and no external
dependencies. Their fine lines and repeated structures remain vector artwork at
any size. Visible captions live in the page so they can wrap independently of
the illustration. Chapter-opening uses are decorative and have empty alt text.
