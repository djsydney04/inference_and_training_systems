# Original AI Almanac illustrations

These SVG drawings were created for AI Almanac. They do not reproduce a vendor
diagram or depict a specific commercial chip or network topology.

The collection contains sixteen drawings. `src/illustration-catalog.ts` assigns
them to chapter openings, course parts, library previews, and explanatory figures.

- `model-study.svg`: token vectors, a causal attention pattern, and a prediction.
  The values and bar lengths are illustrative. Hatching marks future positions.
- `silicon-study.svg`: compute tiles, memory banks, and connecting traces in a
  conceptual accelerator package. This is not a physical floorplan.
- `systems-study.svg`: eight compute nodes and illustrative communication paths.
  The drawing does not prescribe a particular fabric or collective algorithm.
- `tensor-study.svg`: tensor planes and their underlying storage.
- `gradient-study.svg`: contours and an illustrative optimization trajectory.
- `data-study.svg`: documents, token sequences, and packed batches.
- `logic-study.svg`: combinational paths between clocked registers.
- `memory-study.svg`: local storage and progressively wider memory layers.
- `tiling-study.svg`: operand tiles, local reuse, and an output tile.
- `compiler-study.svg`: source, intermediate operations, and scheduled work.
- `pipeline-study.svg`: staggered work, dependencies, and idle slots.
- `cache-study.svg`: logical block lists and shared physical pages.
- `decoding-study.svg`: possible token continuations and one selected path.
- `serving-study.svg`: incoming requests, queueing, workers, and responses.
- `collective-study.svg`: chunks moving around a ring of logical ranks.
- `execution-study.svg`: instruction scheduling, execution, and retirement.

The thirteen expanded studies are generated by the checked-in vector authoring
script. Edit its paths, grids, and patterns, then regenerate with:

```sh
node scripts/generate-illustrations.mjs
```

The original model, silicon, and systems drawings remain directly authored SVGs.
All drawings are conceptual: spacing, line lengths, contours, and block sizes do
not report measured timing, numerical values, storage capacity, or vendor layouts.

Each has a 840 × 560 view box, an accessible title and description, and no external
dependencies. Their fine lines and repeated structures remain vector artwork at
any size. Visible captions live in the page so they can wrap independently of
the illustration. Chapter-opening uses are decorative and have empty alt text.
The 29 lesson studies have readable HTML captions and the book's existing figure
numbering and popout controls. They complement the live numerical workbenches.
